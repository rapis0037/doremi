## 0. 제출 전 처리해야 하는 항목

### ✅ 계정 삭제 기능 — Guideline 5.1.1(v) · 구현 완료

`설정 > 로그인 정보 > 계정 삭제` → 확인 다이얼로그 → Firestore 보호자 문서 삭제 →
Firebase 인증 계정 삭제(최근 로그인이 오래됐으면 재인증) → 로컬 설정 초기화 →
가입 화면 복귀.

`firestore.rules`의 `allow delete`도 본인 문서에 한해 허용으로 바꿨다.
**Firestore 규칙은 따로 배포해야 적용된다.**

```bash
firebase deploy --only firestore:rules
```

**이 변경이 포함된 새 빌드를 올려야 한다.** 지금 App Store Connect에 있는 빌드 1에는
삭제 기능이 없다.

### ✅ 개인정보처리방침 URL — 게시 완료

| 용도 | URL |
|---|---|
| 개인정보처리방침 | https://rapis0037.github.io/john-yoon-app-policies/doremi-privacy-policy |

계정 삭제 안내 URL은 Google Play 데이터 삭제 URL 칸에도 그대로 쓸 수 있다.

> 문구도 새 방침 내용에 맞추는 것. 리뷰어가 자주 확인하는 지점이다.

### 🟠 구독 관리 UI가 실제 상품 없이 들어가 있음 — Guideline 2.1

`설정 > 구독 관리`에 "프리미엄 구독 플랜을 준비하고 있어요", 구매 복원 버튼은
"구독 상품 연결이 완료되면 사용할 수 있어요" 스낵바만 띄운다
(`main_settings_dialog.dart:149-275`).

**1.0.0에서는 '구독 관리' 행을 숨기는 것을 권장한다.** 실제 IAP 상품을 붙일 때 되살리면 된다.

### 🟠 로그인을 강제함 — Guideline 5.1.1(i)

음 학습 자체는 계정과 무관한데 첫 화면이 가입/로그인이다(`main.dart:69`).
계정 기반 기능이 아닌 경우 로그인 강제는 리젝 사유가 될 수 있다.

- 최선: '로그인 없이 둘러보기'(게스트) 진입 추가
- 차선: 아래 심사 메모의 설명 문구로 방어 (보호자 계정에 아이별 학습 설정을 저장·동기화)

### 🟡 iPad

빌드가 iPhone+iPad 유니버설이라 **13인치 iPad 스크린샷이 필수**이고, 리뷰어가 iPad에서
카메라 AR 모드까지 테스트한다. iPad 레이아웃이 아직 자신 없으면 iPhone 전용
(`TARGETED_DEVICE_FAMILY = 1`)으로 바꿔 새 빌드를 올리는 편이 안전하다.

### 🟡 Kids 카테고리는 선택하지 말 것

대상이 4~8세라 눈이 가지만, Kids 카테고리는
- 아동 개인정보 수집 금지 (이 앱은 이메일·아이 나이·닉네임을 수집한다)
- 부모 게이트 없는 외부 링크 금지 (카카오 채널, 인스타그램, 스토어 구독 링크)

두 가지에서 바로 걸린다. **교육 카테고리 + 4+ 등급**으로 가는 게 맞다.

## 5. 그 외 제출 항목

- **수출 규정**: 암호화 사용 = HTTPS 표준 암호화만 → 면제 대상.
  매번 묻지 않게 하려면 `ios/Runner/Info.plist`에 추가:
  ```xml
  <key>ITSAppUsesNonExemptEncryption</key>
  <false/>
  ```
- **Sign in with Apple**: Google 로그인이 있으므로 필수 (구현되어 있음).
  Apple Developer의 App ID에 Sign In with Apple capability가 켜져 있고
  Firebase Console > Authentication에 Apple 공급자가 활성화돼 있는지 확인.
- **출시 방식**: 첫 버전은 '수동 출시'로 두면 승인 후 스토어 노출 시점을 직접 고를 수 있다.
