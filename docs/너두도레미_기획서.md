## 2. 배경 및 목적

유아기 음악 교육의 첫 번째 장벽은 **"어렵다"는 인식**이다.  
악보를 읽거나 악기를 배우기 전에, 먼저 음에 친숙해지는 경험이 필요하다.

**너두! 도레미!** 는 도·레·미·파·솔·라·시 8음을 색깔과 도형으로 매핑하여  
터치 한 번으로 소리를 탐색하고, AR 카메라로 현실 공간에서 음을 만나고,  
간단한 드래그 챌린지로 첫 악보를 경험하게 하는 **놀이형 음악 입문 앱**이다.

---

## 3. 타겟 사용자

| 구분 | 설명 |
|---|---|
| 주 사용자 | 4~8세 유아·아동 (직접 조작) |
| 보조 사용자 | 부모·보호자 (설치, 설정, 관찰) |
| 사용 환경 | 스마트폰·태블릿, 가로·세로 모든 방향 |

**핵심 페르소나**  
- 글을 아직 못 읽지만 색과 모양으로 구분하는 5세 아이  
- 피아노 학원을 다니기 전 음에 대한 호기심을 키우고 싶은 7세 아이  
- 아이에게 음악을 쉽게 접하게 해주고 싶은 학부모

## 5. 화면 구성 및 기능

### 5.1 홈 화면

- 고양이 마스코트와 앱 타이틀 표시
- 3단계 학습 카드 (1·2·3단계)
- 우측 상단: 설정 (로그인 정보, 개인정보 처리방침, 회사 정보)

---

### 5.2 1단계 — 톡톡! 한 음 익히기

**목표**: 8개 건반 중 하나를 선택하고 해당 음정의 도형이 오선지에 안착하는 과정을 관찰한다.

**흐름**:
```
건반 선택 → 건반 위 도형 탭 → 도형 비행 애니메이션
         → 오선지 착지 + 파티클 팡파레 → 계이름 팝업 표시
```

**주요 기능**:
- 8음(흰 건반 8개 + 검은 건반 5개) 피아노 건반 렌더링
- 선택한 음의 도형만 건반 위에 표시 (나머지 비표시)
- 선택 음 진행 시 건반이 아래로 이동, 오선지 상단 등장
- 사인파 + 배음 합성으로 피아노 음색 재현 (외부 음원 파일 없음)
- 팝업 탭 시 초기화 → 다른 음 선택 가능

---

### 5.3 2단계 — AR 톡톡! 한 음 만나기

**목표**: 실제 카메라 화면 위에서 음정 도형을 체험한다.

#### 모드 선택 화면
| 모드 | 설명 | 상태 |
|---|---|---|
| 톡톡 Lite | 카메라 배경 위에 오선지+건반 오버레이 | 구현 완료 |
| 톡톡 Space | 피아노 건반을 바닥으로 인식하는 공간 AR | 개발 예정 |

#### 톡톡 Lite 흐름
```
카메라 권한 획득 → 카메라 프리뷰 표시
→ 반투명 오버레이 위에 건반 렌더링
→ 1단계와 동일한 학습 흐름 진행
```

---

### 5.4 3단계 — 음정 챌린지!

**목표**: 도(하트)를 드래그해서 건반 위 도 위치에 가져다 놓는다.

**흐름**:
```
홈 건반 화면 → 핑크 하트(도) 탭/터치 시작
→ 드래그 or 터치로 이동 → 도 건반 영역 인식
→ 착지 성공: 컨페티 + 악보 재생 (4분음표 4개 + 온음표)
→ 착지 실패: 하트 원위치 복귀 + 가이드 글로우
→ 팡파레 완료 후 팝업 → 탭으로 리셋
```

**악보 재생 순서**: 도♩ 도♩ 도♩ 도♩ 도𝅗𝅥 (강세 있는 박자감)

## 6. 반응형 설계 원칙

`ResponsiveViewport`가 디바이스 화면을 단일 기준 캔버스로 변환한다.

| 방향 | 기준 캔버스 크기 |
|---|---|
| 세로 | 412 × 915 |
| 가로 | 915 × 412 |

- 모든 텍스트, 아이콘, 건반, 도형이 **동일 배율**로 축소·확대
- 새 화면 추가 시 최상위 콘텐츠를 반드시 `ResponsiveViewport`로 감쌀 것

## 9. 프로젝트 구조 (현행)

```
doremi/lib/
├── main.dart              앱 진입점 + 루트 네비게이터
├── core/                  모델, 상수 (notes, sceneSize)
├── audio/                 TonePlayer — WAV 합성·재생
├── layout/                KeyboardLayout — 건반 좌표
├── drawing/               Canvas 드로잉 함수 모음
├── painters/              CustomPainter 클래스
├── widgets/               공통 위젯 + 다이얼로그
└── pages/                 화면 단위 위젯
```
